# LeadCatcher: бот для сбора и квалификации заявок

Бот превращает трафик с рекламы в готовые заявки для отдела продаж. Клиент за минуту отвечает на несколько вопросов кнопками. Бот оценивает заявку (горячая, тёплая или холодная) и сразу отправляет её в чат продаж с кнопками «беру», «связался», «продано».

Заявки с форм сайтов попадают туда же: в тот же чат, CSV и Google Sheets.

Демо сделано для вымышленной компании **SunBay Solar**, которая ставит солнечные панели. Вопросы лежат в `funnel.json`.

## Что умеет

**Клиент**
- Приходит по ссылке из рекламы вида `t.me/ваш_бот?start=fb_spring`. Бот запоминает источник (`fb_spring`), и в статистике видно, какая реклама приносит заявки.
- Отвечает кнопками. Текстовые ответы проверяются: телефон, email, длина.
- Телефон отправляет одной кнопкой «📱 Share my phone number». Чужой контакт бот не примет.
- Может вернуться назад, пропустить необязательный вопрос, проверить ответы перед отправкой или начать заново.
- Если бросил анкету на середине, через час получит одно напоминание с кнопкой «Continue».
- Прогресс хранится в базе, поэтому перезапуск бота ответы не сбрасывает.

**Отдел продаж**
- Каждая заявка приходит в чат карточкой: оценка, контакты, ответы, источник, срок, в который надо перезвонить.
- Кнопка **🙋 I'll take it** закрепляет заявку за менеджером, и второй менеджер её уже не возьмёт. Клиент получает сообщение «Max из SunBay Solar занимается вашей заявкой».
- Дальше статусы: **📞 Contacted**, **✅ Won**, **❌ Lost**. Все копии карточки обновляются сразу.
- Если горячую заявку не взяли за 15 минут, бот напомнит в чате ответом на карточку. Сроки задаются в `funnel.json`.
- `/stats` показывает статистику за 7 дней: сколько человек начали и закончили анкету, конверсию, горячие и тёплые заявки, лучшие источники, среднее время до ответа менеджера.
- `/leads` выводит последние заявки, `/export` выгружает CSV для Excel или Google Sheets.
- Можно подключить общий чат продаж: добавьте бота в группу, отправьте там `/chatid` и впишите номер в `LEADS_CHAT_ID`.

**Интеграции**
- **Google Sheets**: каждая заявка становится строкой, а смена статуса обновляет ту же строку. Google Cloud не нужен, достаточно скрипта на 5 минут из `integrations/google_sheets.gs`.
- **Вебхуки** в Zapier, Make, n8n или любую CRM: HubSpot, Pipedrive, amoCRM и другие через их «webhook trigger». Тело подписывается HMAC (`X-Signature`).
- **Доставка надёжная.** Заявка сначала сохраняется в базу, потом отправляется. Если CRM недоступна, бот повторит попытку через 1, 5, 30, 120 и 720 минут.
- **Формы сайтов.** `POST /api/leads` принимает заявку с любого сайта. Пример формы лежит в `integrations/website_form.html`. Защита от спама: скрытое поле-ловушка, лимит запросов с одного адреса и список разрешённых сайтов.

## Демо-режим

`DEMO_MODE=true`: посетитель после отправки заявки получает копию карточки «как у отдела продаж» с рабочими кнопками, но только для своей заявки.

Команды `/stats`, `/leads` и `/export` тоже доступны. `/stats` показывает только общие цифры, `/leads` и `/export` показывают только заявки самого посетителя. Чужие телефоны демо-посетитель не увидит.

## Как поменять вопросы под клиента

Код трогать не нужно, всё в `funnel.json`:
- `steps` — вопросы по порядку. Типы: `choice` (кнопки), `text`, `phone`, `email`.
- У кнопок есть `score`, баллы за ответ. За текстовый ответ тоже можно дать баллы: `"score": 5`.
- `"optional": true` добавляет к вопросу кнопку «Skip».
- У вопроса `text` тоже могут быть `options`. Это кнопки быстрых ответов, например популярные города, но свой ответ можно и напечатать. Под текстовыми вопросами бот сам пишет «Type your answer in the message box».
- `"field": "name" | "phone" | "email"` переносит ответ в карточку и CSV отдельной колонкой.
- `scoring` — пороги: от `hot` баллов заявка горячая, от `warm` тёплая.
- `finish` — что ответить клиенту для каждого типа заявки. `{name}` подставляет имя.
- `sla_minutes` — за сколько минут надо взять заявку, иначе бот напомнит в чате.

При ошибке в файле бот не запустится и напишет, что исправить: например, «step 2 (bill): a choice step needs at least 2 options».

## Google Sheets за 5 минут

1. Создайте таблицу, затем **Расширения** → **Apps Script**. Вставьте код из `integrations/google_sheets.gs`.
2. Замените `SECRET` на длинный случайный текст.
3. **Начать развертывание** → **Новое развертывание** → **Веб-приложение**. Выберите «Запуск от имени: я» и «Доступ: все».
4. Скопируйте адрес и допишите в конец `?key=ВАШ_SECRET`. Вставьте получившийся адрес в `WEBHOOK_URLS` в `.env`.

## Запуск

1. Создайте нового бота в @BotFather.
2. Выполните (PowerShell):

```powershell
python -m venv .venv
```
```powershell
.venv\Scripts\pip install -r requirements.txt
```
```powershell
copy .env.example .env
```

3. В `.env` впишите `BOT_TOKEN` и `ADMIN_IDS`. Свой id покажет команда `/chatid` в боте.
4. Запустите:

```powershell
.venv\Scripts\python -m bot
```

Ссылка для рекламы: `https://t.me/ИМЯ_БОТА?start=название_кампании`.

> Пока бот работает на сервере, не запускайте его на компьютере с тем же токеном: Telegram разрешает только одну копию.

## На сервере (папка `deploy`)

В `deploy/docker-compose.yml` добавьте сервис:

```yaml
  leadcatcher-bot:
    <<: *bot
    build: ../leadcatcher-bot
    env_file: ../leadcatcher-bot/.env
    environment:
      DATABASE_URL: sqlite+aiosqlite:////app/data/leads.db
      TRUST_PROXY: "true"
    volumes:
      - leads-data:/app/data
    mem_limit: 384m
```

Добавьте `leads-data:` в `volumes:`, а бота в цикл `backup.sh`. Формы сайтов заработают после этого блока в `Caddyfile`:

```
leads.a-kalikas.duckdns.org {
	reverse_proxy leadcatcher-bot:8080
}
```

## Тесты

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
```
```powershell
.venv\Scripts\python -m pytest
```

22 теста. Что они проверяют:
- **анкета**: путь клиента от `/start` до отправки, неверный ввод, «назад» и «пропустить», старые кнопки, чужой контакт, повторное нажатие «Send»;
- **оценка заявок** и понятные ошибки в `funnel.json`;
- **отдел продаж**: кнопки и смена статусов, «взять» может только один менеджер, права в группе и в демо, напоминание о просроченной горячей заявке, напоминание о брошенной анкете, `/stats`, `/leads`, `/export`;
- **формы сайтов**: проверка полей, ловушка для ботов, разрешённые сайты, лимит запросов;
- **вебхуки** на настоящем локальном HTTP-сервере: подпись, повтор при ошибке CRM, отказ после 6 попыток, ответ Apps Script `{"ok": false}` и страница ошибки упавшего скрипта.

## Структура

```
bot/
  __main__.py      запуск: бот + приём форм + фоновые проверки
  config.py        настройки из .env
  funnel.py        анкета из funnel.json, баллы, проверка ответов (чистая логика)
  db.py            таблицы: leads, lead_cards, outbox
  repo.py          запросы к базе, статистика
  texts.py         тексты и карточка заявки
  keyboards.py     кнопки
  notify.py        карточки в чат продаж
  watcher.py       напоминания о сроках и брошенных анкетах
  webhooks.py      отправка в Google Sheets / CRM с повторами
  web.py           POST /api/leads для форм сайтов
  export.py        CSV
  handlers/
    funnel_flow.py анкета
    sales.py       кнопки на карточке
    admin.py       /stats /leads /export /chatid
integrations/      google_sheets.gs, website_form.html
funnel.json        вопросы демо-компании
tests/
```
